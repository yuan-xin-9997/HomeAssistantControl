# Home Assistant Control 1.0.0

First paid release.

## Highlights

- Local-first control center for compatible Mijia devices and SunLogin smart plugs
- Windows and macOS clients, plus a browser dashboard
- Mijia QR/password login and device import
- Local miIO/MIoT control generated from each model's specification
- SunLogin C1/C2/P1 local plugs and C2-BLE-V3 cloud plugs
- Multi-step scenes and activity history
- Multi-client center with pairing code
- Offline machine-bound activation, 2 computers per license, 1 year of updates
- Demo mode with sample data
- SEO-ready store, guide and compatibility pages

## Install

1. Download `HomeAssistantControl-Setup.exe`.
2. Run the installer. Windows may show a SmartScreen warning because the build is not code-signed.
3. Start the app. Copy the machine code from the activation screen.
4. Buy a license at <https://hacontrol.yuan-xin.top/> and submit the machine code.
5. Paste the `HAC-...` activation code into the app and click **Activate**.

## Notes

- Real-device control requires a paid license. The installer and demo mode are free.
- Local control works without internet; Xiaomi login/import and SunLogin cloud plugs need internet.
- The app is an independent product, not affiliated with Xiaomi, Mijia, SunLogin/Oray or the Home Assistant project.
- macOS distribution requires developer signing; this release contains the Windows installer.
