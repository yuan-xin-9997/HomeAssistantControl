# Security

If you believe you found a security issue in Home Assistant Control, do not open a public issue with exploit details. Email <support@yuan-xin.top> with:

- the affected version and platform;
- a short description and impact;
- reproduction steps, if safe to share;
- whether you want to be credited.

Please do not access other people's devices, accounts or data. We aim to acknowledge reports within three business days.

The app is designed for a trusted LAN. Do not expose the control center's port 4010 to the internet. The center uses HTTP between clients and the center; use it only on a trusted private network.
